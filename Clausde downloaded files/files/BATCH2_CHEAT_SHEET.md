## DO THIS FOR EACH TOOL (same steps every time)

1. In VS Code left panel → right-click "app" → New Folder → type folder name → Enter
2. Right-click that folder → New File → type: page.tsx → Enter
3. Open my tool file → Cmd+A → Cmd+C
4. Click your blank page.tsx → Cmd+V → Cmd+S
5. Browser → localhost:3000/FOLDER-NAME → done!

## After adding all tools, push to GitHub

In Terminal:
  git add .
  git commit -m "add tip calculator, bmi, percentage, age, password, text case, discount tools"
  git push

Vercel deploys in 30 seconds → all tools live!
