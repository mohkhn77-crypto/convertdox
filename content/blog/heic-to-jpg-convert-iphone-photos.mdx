## What is HEIC and Why Does It Exist?

HEIC stands for **High Efficiency Image Container**. Apple started using it as the default photo format on iPhone in 2017 (iOS 11 and later) because:

- HEIC files are roughly **50% smaller** than JPG with the same quality
- They support advanced features like Live Photos and depth data
- They save iCloud storage space

The problem? Most non-Apple systems don't support HEIC natively:

- ❌ Windows 10 (without paid extension)
- ❌ Android phones
- ❌ Most web platforms (LinkedIn, Twitter X, many job application portals)
- ❌ Microsoft Office (older versions)
- ❌ Most printing services

That's why you need to convert HEIC to JPG — the universally supported format.

## Method 2: Convert HEIC to JPG on iPhone (Before Sending)

If you regularly send photos from iPhone and want to skip the conversion step entirely, you can change your iPhone's default photo format.

**Settings to change:**

1. Open **Settings** on your iPhone
2. Tap **Camera**
3. Tap **Formats**
4. Select **Most Compatible** (instead of "High Efficiency")

From this point on, your iPhone will save new photos as JPG instead of HEIC.

**Trade-off:** New photos will take more storage space (about 2x), but they'll work everywhere.

**Note:** This only affects future photos. Existing HEIC photos in your camera roll remain HEIC.

## Method 3: Convert HEIC to JPG on Mac (Built-in)

If you're on a Mac, macOS has HEIC conversion built into the Preview app.

**Steps:**

1. Open your HEIC file in **Preview** (default image viewer)
2. Click **File** menu in the top bar
3. Click **Export...**
4. Change **Format** to **JPEG**
5. Adjust quality slider if desired
6. Click **Save**

**Pros:** Free, no internet required, full quality control.

**Cons:** Only works on Mac. Tedious for batch conversions.

## Method 4: Convert HEIC to JPG on Windows (Built-in)

Windows 10 and 11 have basic HEIC support if you install the free extensions from Microsoft Store.

**Setup (one-time):**

1. Open **Microsoft Store**
2. Search for **"HEIF Image Extensions"** → install (free)
3. Search for **"HEVC Video Extensions"** → install (paid, $0.99) OR use an alternative method

**To convert HEIC to JPG:**

1. Right-click the HEIC file
2. Click **Open with** → **Paint**
3. Click **File** → **Save as** → **JPEG picture**
4. Choose location and save

**Pros:** Free (mostly), no internet required after setup.

**Cons:** Extension required, paid component for video files, no batch conversion.

## Method 5: Convert HEIC to JPG Using Command Line (Technical)

For developers and power users, you can convert HEIC files using free command-line tools.

**On Mac/Linux:**

```bash
brew install imagemagick
magick mogrify -format jpg *.heic
```

**On Windows (PowerShell):**

```powershell
# After installing ImageMagick
magick mogrify -format jpg *.heic
```

**Pros:** Free, fast, can batch convert hundreds of files at once, scriptable.

**Cons:** Requires technical knowledge, terminal/command prompt skills.
