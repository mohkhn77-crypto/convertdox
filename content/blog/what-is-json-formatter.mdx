You've just copied a JSON payload from an API response and it looks like this:

```
{"user":{"id":1,"name":"Alice","roles":["admin","editor"],"settings":{"theme":"dark","notifications":true}}}
```

A JSON formatter turns that into:

```json
{
  "user": {
    "id": 1,
    "name": "Alice",
    "roles": ["admin", "editor"],
    "settings": {
      "theme": "dark",
      "notifications": true
    }
  }
}
```

## What Does a JSON Formatter Do?

A JSON formatter (also called a JSON beautifier) does three things:

1. **Indents** nested objects and arrays so the hierarchy is obvious
2. **Validates** the JSON syntax and points to errors by line number
3. **Minifies** JSON when you need compact output for production

## Why Minified JSON Exists

APIs send minified JSON to save bandwidth. Every space and newline is a byte. For a large dataset served millions of times a day, those bytes add up. You read pretty-printed JSON; servers send minified JSON.

## Common JSON Errors

| Error | What it means |
|---|---|
| Unexpected token | Usually a trailing comma or missing quote |
| Unexpected end | The JSON is cut off — common with truncated API responses |
| Property name must be a string | You used single quotes instead of double quotes |

## JSON vs JavaScript Objects

JSON looks like a JavaScript object but it isn't one. Key differences:
- All keys must be double-quoted strings in JSON
- No comments allowed in JSON
- No `undefined` — only `null`
- No trailing commas

A formatter catches these mistakes before they hit production.
